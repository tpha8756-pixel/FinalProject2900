# Mount Saint Mary College — Faculty & Staff "Simon Says" Game

## How to Run This Project
Because this project uses standard ES6 JavaScript modules (`<script type="module">`), it must be served over HTTP rather than opened directly via `file://`:
1. Open the project folder in **Visual Studio Code**.
2. Right-click `index.html` and choose **Open with Live Server** (or run any local HTTP server such as `npx serve` or `python -m http.server`).
3. Play directly in your browser.

## How to Play
1. Click **Start Game**.
2. Watch which MSMC faculty pad lights up and plays a tone.
3. Click the matching faculty pad to repeat the pattern.
4. Each round adds one new step to the sequence. Clicking an incorrect pad ends the game.
