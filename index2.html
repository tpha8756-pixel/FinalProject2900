How to Play

  1. Click Start Game to start a new game session.
  2. Watch the sequence of Mount Saint Mary College faculty members highlight.
  3. When I shout Simon says you must do as I tell you too
  4. If I dont say anything remain still don't do anything
  5. You are out if caught following invalid command
  6. You are out if also caught refusing to do valid command
